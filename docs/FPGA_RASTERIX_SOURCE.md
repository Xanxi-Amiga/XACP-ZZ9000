# RasterIX FPGA integration — source guide

The `firmware/source/XX19d-RIX/` repository directory (also provided as
`XACP.XX19d-RIX.sources.zip` on the release page) contains the **custom** RasterIX RTL,
the ZZ9000-specific memory and command integration, the MNTZorro IP project,
the Zynq processing-system block diagram and Vivado IP configuration files.

The design targets an MNT ZZ9000 with a Xilinx Zynq XC7Z020 FPGA. It uses
Vivado 2025.2 and the existing Zynq high-performance DDR interface.
The release binary runs at the original 100 MHz fabric clock with one TMU.

## Where to start

In GitHub, browse `firmware/source/XX19d-RIX/`; alternatively extract
`XACP.XX19d-RIX.sources.zip` from the release page:

- Under `firmware/source/XX19d-RIX/fpga/`, locate the sole `ZZ9000_proto.xpr` — Vivado project;
- In the adjacent `ZZ9000_proto.srcs/sources_1/bd/zz9000_ps/` directory, open `zz9000_ps.bd` — Zynq block design;
- Under `fpga/`, locate the `rtl/RasterIX/` directory — renderer and integration RTL;
- Under `firmware/source/XX19d-RIX/arm/ZZ9000_proto.sdk/` — ARM firmware/FSBL sources.

The directory names above are **build paths**, not the firmware's public version name.
They are retained because renaming established Vivado/HDL references may break
reconstruction.

The project metadata has been checked and its referenced source files are
present. On 18 October 2026 a clean extraction passed Vivado 2025.2 project
opening, block-design validation, IP generation and FPGA synthesis. Placement,
routing, and a regenerated BOOT were **not** validated.

The provided project is a **source snapshot**; it is not a guaranteed one-click
rebuild on a different computer. Regenerate AMD/Xilinx IP products with a suitable
licensed Vivado installation. Board-specific constraints, tool versions and build
output must be checked before flashing. The project has been synthesized after cleanup, but not fully placed/routed,
and the distributed binary remains the independently validated BOOT.

The source distribution excludes vendor-generated implementation HDL, caches,
compiled Xilinx BSP archives and synthesis checkpoints. Those are to be generated
by their corresponding licensed tools. Their omission does not remove the
custom RTL, block design or IP customization metadata.

The original ZZ9000 board and firmware are from MNT Research. Third-party HDL

IP redistribution terms before repackaging autogenerated output.

This design is for the ZZ9000, not a plug-in bitstream for the Z3660 or another
Zynq system. Its architecture may still be useful as a reference for independent
ports.
