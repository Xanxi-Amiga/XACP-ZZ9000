# Drivers

This directory contains driver-related additions and compatibility work for XACP / ZZ9000.

Current content:

- `ZZ9000AX-Fitzsteve/` — modified ZZ9000AX audio driver variant for compatibility with XACP game ports using sound effects together with MP3 or ZZMIDI music.

See the individual subdirectories for version history, source, binaries and licensing information.
