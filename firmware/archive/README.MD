# Archived ZZ9000 firmware builds

This directory contains superseded public XACP firmware binaries, retained
for historical reference and rollback.

The current firmware is `../BOOT_XX19d-RIX.bin` (XACP v1.8).
The previous XX19c binary is `BOOT_XX19c.bin`; its source is
`../source/XX19c/`.

These images are specific to the ZZ9000 and must not be used on other boards.
