# Build and verification

The distributed `BOOT_XX19d-RIX.bin` matches the BOOT image produced by the
archived build manifest, verified by SHA-256.

The original Vivado source tree was validated against the route-generated RTL
files and the FPGA integration changes. The distributable source snapshot
removes autogenerated outputs and updates its project metadata to eliminate
a machine-specific path and an incremental synthesis checkpoint. The XPR XML was repaired to remove an orphaned FileInfo/File tag and six
stale machine-local ImportPath annotations. All 100 project source file paths
resolve in the distribution. On 18 October 2026, a clean extracted snapshot
opened under Vivado 2025.2, validated its block design, regenerated its IP
outputs, and completed FPGA synthesis. These checks did not regenerate the
production BOOT, and placement/routing of this snapshot was not validated.
No custom RTL functionality was changed during packaging.

Vivado 2025.2, the Xilinx/AMD IP library, ARM toolchain and appropriate board
configuration are needed for rebuilding. **The sanitized sources have not
been rebuilt or tested on hardware**, so any newly generated BOOT must be
validated before installation or redistribution.

The original RTL/FSBL/ARM hashes and the reference BOOT hash are recorded in
`PROVENANCE.json` for independent verification.
