# Firmware tools

This directory contains utilities used to install, update, inspect or maintain
the ZZ9000 firmware environment.

These tools are not XACP applications and should not be listed as part of the
XACP application catalogue.

Each utility retains its own original authorship and license information.

Current tool:

- `ZZFwUpdate/` — historical ZZFwUpdate 2.1 by Dimitris Panokostas (MiDWaN),
  redistributed under GPL-3.0-or-later for use with the FWUP implementation
  used by the XACP firmware branch.
