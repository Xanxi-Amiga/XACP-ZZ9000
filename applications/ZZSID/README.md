# ZZSID - SID audio applications for ZZ9000 / XACP

This directory groups Commodore 64 SID-related projects for AmigaOS using the ZZ9000/XACP platform.

## Available now

- **[ZZSIDPlayGUI 1.0](ZZSIDPlayGUI/README.md)** - Native AmigaOS 3.x SID player with ARM Core1 reSID emulation, 1SID/2SID stereo playback and AHI audio output.

## Future work

- **playsid.library support** (planned)
- **SID MIDI support** (planned)

These future projects have not been released.

## Project structure

ZZSIDPlayGUI is the first released application in the ZZSID family. Additional SID-related projects may be added here in the future.

See [the XACP repository](../../README.md) for platform requirements.
