# ZZTeapot

ZZTeapot is an XACP demo for the Amiga’s ZZ9000 card, featuring the classic Utah teapot — a “Hello, world!” of 3D graphics.

The demo uses GL-style rendering performed entirely in software on the ZZ9000’s ARM processor. It explores the rendering foundation for a future game port.
