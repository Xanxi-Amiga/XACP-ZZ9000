# Licensing

ZZDarkForcesNEXT is distributed as two separately built parts.

## GPL-covered Core1 component

`zzdf.bin` contains The Force Engine-derived code and the ZZ9000/XACP Core1 port.

The Force Engine is licensed under:

```text
GNU General Public License v2.0
```

The corresponding TFE-derived/Core1 source for the distributed `zzdf.bin` is therefore published under GPL-2.0.

The public source repository should include the upstream GPL-2.0 license text and the complete corresponding source/build material for the released blob.

## Closed-source 68k launcher

The Amiga 68k launcher:

```text
ZZDarkForces
```

is distributed separately as a **closed-source binary**.

Its source code is intentionally not part of the public GPL source repository.

## Original game data

Original *STAR WARS: Dark Forces* commercial game files are not included. A legally obtained copy of the game is required.

## SoundFonts

SoundFonts are separate data files and carry their own licenses. They are not covered by the ZZDarkForcesNEXT/TFE GPL notice simply by being placed in the same release archive.

See:

```text
SOUNDFONT_LICENSES.md
```

before redistributing them.
