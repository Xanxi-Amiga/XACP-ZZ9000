# ZZDarkForcesNEXT

**Work in Progress**

ZZDarkForcesNEXT is an experimental XACP project targeting the ZZ9000.

The project is currently under active development and is not yet ready for general use or release.

Current work includes:

- XACP / Core1 integration
- game engine adaptation
- graphics and audio integration
- MIDI support through ZZMIDI / CAMD
- compatibility and performance testing on classic Amiga hardware

The contents of this directory may change significantly during development.

No stable release is available yet.
