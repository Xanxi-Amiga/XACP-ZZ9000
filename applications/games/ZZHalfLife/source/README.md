# ZZHalfLife 1.0 - Source archive

`ZZHalfLife_1.0_src.zip` includes the ARM engine and game module source,
Core1/RasterIX integration, build scripts, host tests and data preparation
Python tools. The archive includes its own README and license notices.

The separate AmigaOS 68k launcher source is not included. Original Valve
Half-Life game data are not included.
