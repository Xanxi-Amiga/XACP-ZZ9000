# ZZQuakeGL 1.0 Core1 source

Open `ZZQuakeGL/README.txt` for the build instructions and licence details.

From `source/ZZQuakeGL/`, run `sh build_arm.sh all` with the locally installed
Arm GNU 13.2 Rel1 toolchain. This builds all four ARM blobs completely offline.
`ZZQuake640_SOURCES_launcher_and_Core1/Core1_GPL/` contains only the public
Core1 runtime; no private Amiga launcher sources are distributed.

`ZZQuakeGL_1.0_src.zip` is the same corresponding source tree in one file.
