# ZZQuake source

The ARM Core1 component is derived from GPL Quake / quakegeneric code.
Its complete corresponding source is provided in `arm/`, including the exact
upstream tree, ZZ9000/XACP platform code, build script, linker script, patcher,
and the final patched engine tree used to produce the release blob.

The Amiga 68k launcher is a separate proprietary freeware component and its
source code is not part of this public source tree.
