# Solar Winds source provenance

Original program: **Solar Winds**, Terence M. Welsh, © 1999–2010.
Source reference: https://github.com/reallyslickscreensavers/reallyslickscreensavers
Upstream file: `src/solarwinds/solarWinds.cpp`, Git blob `bf29349317c2a86b64e0fc60339a1146929c2427`.
A copy of the original sources with notices is preserved in `upstream/solarwinds/`.

Adaptation replaces the Windows/OpenGL integration with an AmigaOS 68k launcher, Cortex-A9 Core1 simulation/render preparation, and the ZZ9000 FPGA RasterIX renderer. Presets and core simulation equations are retained, with GPU-compatible geometry, blending and history-frame handling. Source includes librixgpu and ZZGL support and their source notices.

Original Solar Winds component: GPL-2.0-or-later. XACP transport components include 0BSD-licensed code. The combined distributed Solar Winds application is offered under GPL-2.0-or-later. Preserve copyright and modification notices when redistributing.
