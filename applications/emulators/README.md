# Emulators

This directory contains XACP / ZZ9000 emulator and CPU-emulation projects.

Current projects:

- **ZZPicoDriveMD** — Sega Mega Drive / Genesis emulator for ZZ9000 / XACP.
- **ZZPicoDriveSMS** — Sega Master System emulator for ZZ9000 / XACP.
- **ZZPPC** — experimental PPC32/FPU execution on ZZ9000 Core1; currently a proof of concept rather than a general PowerPC emulator.
