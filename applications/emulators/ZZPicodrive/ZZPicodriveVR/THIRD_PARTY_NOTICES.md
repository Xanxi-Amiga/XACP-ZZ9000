Modifications in this package:

- `cpu/drc/emit_arm.c`, `emith_xbranch()`: a far-call sequence under
  `#if defined(ZZVR_FAR_CALLS)` for the recompiler code cache; the corresponding
  implementation is in `third_party/picodrive/cpu/drc/emit_arm.c`.
- `cpu/sh2/compiler.c`: `LOOP_DETECTION` and `LOOP_OPTIMIZER` wrapped in
  `#ifndef` so that the build can set them; this package builds with both at 0.
- `tools/mkoffsets.sh` added from upstream PicoDrive (Kai-Uwe Bloem, public
  domain); `pico/pico_int_offs.h` is generated by it at build time.

irixxxx, MAME licence as stated in the files) are compiled unchanged.

`cpu/drc/`, terms as stated in the files). FAME/C, Musashi and emu2413 are
present but not compiled.
