# Source and licensing notes

This milestone only republishes the `librixgpu` C modules and associated headers/API
from the D1a archive, plus factual project notes and test evidence. The implementation
source files under `librixgpu/` carry `SPDX-License-Identifier: 0BSD` notices.
The public repository should retain those notices. If distributing a complete ZZGear
port later, first review the license and provenance of the historic gear sample,
geometry, textures, and any bundled firmware, build assets or vendor headers.

The source snapshot is not a stand-alone packaged game; no 68k executable is included.
See API.md for build and memory integration constraints.
